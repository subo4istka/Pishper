# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## v1 — 2026-08-20

Первый публичный релиз.

### Возможности

- Запись по горячей клавише с вставкой текста в активное окно через буфер обмена.
- Непрерывный режим с VAD: детекция речи по RMS, pre-roll 400 мс, настраиваемая
  пауза отсечки фразы (0,5–5 с).
- Горячие клавиши: комбинации, одиночные клавиши через низкоуровневый
  `WH_KEYBOARD_LL`-хук (клавиша-триггер не попадает в текст), боковые кнопки
  мыши; до двух независимых привязок. Отмена записи по `Escape`.
- Четыре провайдера распознавания: OpenAI, Groq, Deepgram, GigaChat —
  с отдельным API-ключом на каждого.
- 16 языков плюс режим «Русский + English» для смешанной речи; режим перевода
  на английский.
- Кодирование в MP3 на лету с выбором битрейта 16/32/64 кбит/с.
- Шесть звуковых тем, генерируемых в коде; экранный индикатор записи с уровнем
  сигнала.
- Словарь автозамен и фильтр типовых галлюцинаций Whisper.
- Поддержка HTTP/SOCKS-прокси с отдельным переключателем.
- Классификация ошибок API с двумя повторами, учётом `Retry-After` и
  подавлением повторяющихся уведомлений.
- Автозапуск через реестр Windows, статистика использования в
  `~/.pishper/stats.txt`.
- Сборка в одиночный `.exe` через PyInstaller.
