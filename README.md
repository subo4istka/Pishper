## Что это

Pishper живёт в системном трее и не имеет главного окна. Вы работаете в любом
приложении — браузере, редакторе, мессенджере, — нажимаете горячую клавишу,
говорите, нажимаете снова. Распознанный текст вставляется прямо в активное поле
ввода, как будто вы его набрали.

Распознавание выполняется в облаке (OpenAI Whisper, Groq, Deepgram или GigaChat) —
локальная модель не нужна, поэтому приложение весит десятки мегабайт, а не
гигабайты, и работает на любом ноутбуке без видеокарты.

**Зачем это нужно:** диктовать в 3–4 раза быстрее, чем печатать. Длинные
сообщения, коммит-месседжи, промпты к ИИ, ответы в поддержке, черновики
документов — всё это удобнее сказать.

## Возможности

| | |
|---|---|
| 🎙️ **Запись по горячей клавише** | Нажали — говорите, нажали — текст вставлен. `Escape` отменяет запись. |
| 🔄 **Непрерывный режим** | Микрофон открыт постоянно, встроенный VAD сам находит границы фраз и отправляет каждую фразу по мере её окончания. Удобно для длинной диктовки. |
| ⌨️ **Любая горячая клавиша** | Комбинация (`Ctrl+Shift+Space`), одиночная клавиша (например `Ё` — перехватывается низкоуровневым Win32-хуком и не попадает в текст) или боковая кнопка мыши. Можно назначить **две** независимые горячие клавиши. |
| 🌍 **16 языков** | Русский, English, Deutsch, Français, Español, Italiano, Português, 日本語, 中文, 한국어, Українська, Polski, Türkçe, العربية + режим «Русский + English» для речи со смешанной терминологией. |
| 🔁 **Перевод на английский** | Переключатель в трее: транскрипция как есть или сразу перевод на English. |
| 🔌 **4 провайдера** | OpenAI, Groq, Deepgram, GigaChat — ключ для каждого хранится отдельно, переключение мгновенное. |
| 🎚️ **Экономный трафик** | Звук кодируется в MP3 16/32/64 кбит/с прямо на лету: минута речи — это ~240 КБ, а не 2 МБ WAV. Работает на медленном мобильном интернете. |
| 🔊 **Звуковые темы** | Шесть наборов сигналов старта/остановки/отмены (Весна, Минимал, Пузыри, Космос, Нежный, Тик) или полная тишина. |
| 📊 **Индикатор записи** | Полупрозрачная плашка с живым уровнем сигнала — видно, что микрофон слышит вас. |
| ✏️ **Автозамены** | Свой словарь замен: модель упорно пишет «Джейсон» вместо «JSON» — правится один раз в настройках. |
| 🧹 **Фильтр галлюцинаций** | Whisper на тишине любит выдумывать «Подписывайтесь на канал» и «Субтитры сделал…» — такие фразы отбрасываются. |
| 🌐 **Прокси** | HTTP/SOCKS-прокси с отдельным переключателем: URL сохраняется, даже когда прокси выключен. |
| ⏎ **Автоотправка** | Опционально жать `Enter` после вставки — диктуете сообщение в мессенджер, и оно сразу уходит. |
| 🚀 **Автозапуск** | Регистрация в автозагрузке Windows одним переключателем. |

## Установка

### Готовый .exe (рекомендуется)

1. Скачайте `Pishper.exe` со страницы [Releases](https://github.com/subo4istka/Pishper/releases/latest).
2. Запустите. Установка не требуется — это один самодостаточный файл, Python
   ставить не надо.
3. При первом запуске откроется приветственное окно с краткой инструкцией.
4. Откройте **Настройки → Подключение**, выберите провайдера и вставьте API-ключ.

> **SmartScreen.** Файл не подписан сертификатом (подпись стоит от $200/год),
> поэтому Windows покажет «Не удалось запустить приложение». Нажмите
> «Подробнее» → «Выполнить в любом случае». Если не доверяете сборке —
> [соберите свою](#сборка-из-исходников) из этих же исходников.

### Где взять API-ключ

| Провайдер | Ключ | Модели | Комментарий |
|---|---|---|---|
| **Groq** | [console.groq.com/keys](https://console.groq.com/keys) | Whisper Large V3 Turbo / V3 / Distil EN | Бесплатный лимит, регистрация за пару кликов, самая быстрая транскрипция. **Лучший старт.** |
| **Deepgram** | [console.deepgram.com](https://console.deepgram.com) | Nova-3, Nova-2 | Бесплатные стартовые кредиты. Nova-3 умеет code-switching — русский и английский в одной фразе. |
| **OpenAI** | [platform.openai.com/api-keys](https://platform.openai.com/api-keys) | Whisper v1 | Нужен аккаунт с оплаченным балансом. |
| **GigaChat** | [developers.sber.ru/studio](https://developers.sber.ru/studio) | GigaChat-2 Pro / Max, GigaChat Pro / Max | Российский сервис, работает без VPN. Нужны Authorization Data из проекта GigaChat API. |

Ключи хранятся локально в `%USERPROFILE%\.pishper\config.json` и никуда, кроме
выбранного вами провайдера, не отправляются.

## Как пользоваться

| Действие | Как |
|---|---|
| Записать и вставить | Горячая клавиша → говорите → горячая клавиша снова |
| Отменить запись | `Escape` |
| Непрерывный режим | Меню трея → **🔄 Непрерывный режим** |
| Перевод вместо транскрипции | Меню трея → **Перевод → English** |
| Скопировать последнюю фразу | Меню трея → **📋 Последняя фраза** |
| Автоотправка по `Enter` | Меню трея → **⏎ Автоотправка** |

Текст вставляется через буфер обмена (`Ctrl+V` на уровне Win32), поэтому
работает во всех приложениях, включая те, где эмуляция посимвольного набора
ломается. Прежнее содержимое буфера восстанавливается после вставки.

## Настройка

Настройки открываются из меню трея и разделены на три раздела.

**Подключение** — провайдер, API-ключ, модель, прокси и кнопка «Проверить
подключение»: она отправляет короткий тестовый запрос и показывает реальную
задержку до сервиса, чтобы не гадать, почему ничего не работает.

**Распознавание** — язык, режим (транскрипция / перевод), подсказка модели
(до 400 символов — задаёт стиль пунктуации и написание терминов), пауза для
отсечки фразы в непрерывном режиме (0,5–5 с), качество записи (битрейт MP3).

**Управление** — назначение горячих клавиш (нажмите кнопку и просто нажмите
желаемую клавишу или кнопку мыши), звуковая тема, индикатор записи, автозапуск,
словарь автозамен.

Статистика использования (число сессий и суммарные минуты записи) пишется в
`%USERPROFILE%\.pishper\stats.txt`.

## Как это работает

```
горячая клавиша (pynput / Win32 LL-хук)
        │
        ▼
микрофон 16 кГц mono int16 ──► lameenc ──► MP3 16/32/64 кбит/с
        │                                        │
        │  непрерывный режим: VAD по RMS,         ▼
        │  pre-roll 400 мс, отсечка по паузе   HTTP (httpx / openai SDK)
        │                                        │
        │                                        ▼
        │                          Whisper / Nova / GigaChat API
        │                                        │
        ▼                                        ▼
  индикатор + звуки          фильтр галлюцинаций → автозамены
                                                 │
                                                 ▼
                              буфер обмена + Ctrl+V в активное окно
```

Ключевые решения, если будете читать код:

- **Очередь транскрипции.** Отдельный рабочий поток разбирает очередь строго
  по порядку — в непрерывном режиме фразы не перемешиваются, даже если API
  отвечает вразнобой.
- **Низкоуровневый хук.** Одиночная клавиша перехватывается через
  `WH_KEYBOARD_LL` на выделенном потоке с собственным message pump, поэтому
  клавиша-триггер не попадает в набираемый текст. Callback хука только
  выставляет флаг события — вся работа уходит в другой поток, иначе Windows
  снимет «медленный» хук.
- **MP3 вместо WAV.** Кодирование идёт на лету, а `lameenc` отдаёт настоящие
  `bytes`, а не `bytearray`: `httpx` классифицирует `bytearray` как итерируемое
  и переходит на chunked-передачу по одному байту на чанк — это было
  девятикратное замедление загрузки.
- **Ретраи и понятные ошибки.** `core/errors.py` классифицирует сбои (сеть,
  таймаут, лимит, ключ, сервер), уважает `Retry-After`, делает две повторные
  попытки и показывает человеческий текст, а не трейсбек. Одинаковые ошибки
  не повторяются в уведомлениях чаще раза в 20 секунд.

### Структура проекта

```
main.py                  оркестратор: хуки, очередь задач, состояние
core/config.py           настройки (dataclass ↔ JSON), провайдеры, языки
core/recorder.py         запись по горячей клавише → MP3
core/continuous.py       непрерывный режим с VAD
core/transcriber.py      API четырёх провайдеров, фильтр галлюцинаций
core/errors.py           классификация ошибок и ретраи
core/typer.py            вставка текста через Win32-буфер обмена
core/sounds.py           звуковые темы (генерируются кодом, не файлами)
core/autostart.py        автозагрузка через реестр Windows
core/stats.py            статистика использования
ui/tray.py               иконка и меню в трее
ui/settings_window.py    окно настроек
ui/hotkey_recorder.py    захват горячей клавиши
ui/overlay.py            индикатор записи с уровнем сигнала
ui/welcome.py            приветственное окно
tools/diagnostics/       скрипты проверки окружения при отладке сборки
```

## Сборка из исходников

Требуется Windows 10/11 и Python 3.10+ (сборки в релизах делаются на 3.14).

```bash
git clone https://github.com/subo4istka/Pishper.git
cd Pishper
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Собрать одиночный `.exe`:

```bash
pip install -r requirements-dev.txt
pyinstaller Pishper.spec --noconfirm
```

Готовый файл появится в `dist\Pishper.exe` (≈60 МБ). Спецификация уже настроена:
исключены неиспользуемые модули PyQt6 и тяжёлые научные библиотеки, включён
`optimize=2`, добавлены TLS-сертификаты `certifi` и платформенные бэкенды
`pynput`. Если в системе есть [UPX](https://upx.github.io/), он подключится
автоматически и уменьшит размер.

Спецификация просит `strip` и `upx`, которых в Windows по умолчанию нет:
PyInstaller напечатает трейсбек `FileNotFoundError: [WinError 2]`, продолжит
сборку и вернёт код 0. Это ожидаемо — сборка валидна.

Проверить окружение перед сборкой:

```bash
python tools/diagnostics/check_imports.py
```

## Требования

- Windows 10 или 11 (проект плотно использует Win32 API: хуки, буфер обмена, реестр)
- Микрофон
- Интернет и API-ключ одного из провайдеров
- Для запуска из исходников — Python 3.10+

## Приватность

- Аудио отправляется только выбранному вами провайдеру и только на время
  запроса; локально записи не сохраняются.
- API-ключи, настройки и статистика лежат в `%USERPROFILE%\.pishper\` и никуда
  не передаются.
- Телеметрии, аналитики и автообновления в приложении нет.
- Политику хранения запросов смотрите у самого провайдера — правила у OpenAI,
  Groq, Deepgram и GigaChat разные.

## Решение проблем

**Горячая клавиша не срабатывает.** Другое приложение могло её занять
(например, `Ctrl+Shift+Space` перехватывают некоторые IDE). Назначьте другую
в **Настройки → Управление**. Если целевое окно запущено от администратора,
Windows не пропустит в него ввод от обычного процесса — запустите Pishper тоже
от администратора.

**Текст не вставляется.** Приложение-получатель может блокировать вставку из
буфера. Проверьте меню трея → **📋 Последняя фраза**: если текст там есть,
распознавание работает, проблема во вставке.

**«Ошибка сети» при работающем интернете.** Провайдер может быть недоступен из
вашего региона — включите прокси в **Настройки → Подключение** или используйте
GigaChat. Кнопка «Проверить подключение» покажет, доходит ли запрос.

**Распознаётся не тот язык.** В **Настройки → Распознавание** язык по умолчанию
русский. Для речи со смешанной терминологией выберите «Русский + English».

**На тишине появляется случайный текст.** Whisper галлюцинирует на шуме;
типовые фразы уже отфильтрованы, остальное можно добавить в
`_HALLUCINATION_PATTERNS` в [core/transcriber.py](core/transcriber.py).
